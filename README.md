# Clínica Veterinária Anvet — site

Site institucional publicado pelo GitHub Pages em https://lunacorex.github.io/Anvet/.

HTML, CSS e JavaScript estáticos, sem bibliotecas nem etapa de build obrigatória. Fontes, imagens e vídeos são servidos pelo próprio site.

- `docs/manutencao.md`: como editar textos, horários e contatos
- `docs/midias.md`: origem, versões e padrão de cada foto e vídeo
- `docs/hospedagem-e-cabecalhos.md`: o que está ativo no GitHub Pages e o que está só preparado
- `docs/relatorio.md`: mudanças da revisão de outubro de 2026 e medições

As páginas de Política de Privacidade e Termos de Uso são minutas e dependem de validação da clínica e de um profissional de direito.
